# Praktikantonelli's Dotfiles

Dotfiles for some some tools I use, including:

- [Zellij](./config.kdl)
- [Starship](./starship.toml)
- nushell [env](./env.nu) + [config](./config.nu)

# Paths (Windows)
- Zellij: ~/AppData/Roaming/Zellij/config/
- Starship: ~/.config/
- nushell: ~/AppData/Roaming/nushell/

> [!NOTE] 
> NeoVim is in its own repository [here](https://github.com/praktikantonelli/lazyvim-config)
